## Offline transport contract

Physical Zima PID3969886: 13/13 transport tests; PID3970587: 27/27 combined explicit test classes. The fixture planner constructs a fixed EUR/USD daily HTTPS request with a public fake key, and configures a zero-retry HTTPAdapter; it never sends a request. The simulated response evaluator rejects redirects, authentication/rate-limit errors, unexpected HTTP status/content type, oversized or malformed bodies, duplicate JSON keys, invalid constants, and reports fixed error codes. Successful shape qualification remains non-admitted. This is not a tested live transport: TLS verification, egress restrictions, real streaming/decompression, total wall-clock deadline, durable single-attempt accounting and secure real-key handling remain to be implemented/qualified before admission. No real credentials or provider requests used.

## Offline exclusive attempt and deadline QA

Physical Zima PID3990533: 43/43 combined explicit test classes, including 10 new attempt tests. The experiment creates one exclusive 0600 receipt in a caller-supplied owner-private 0700 directory, fsyncs file and directory before launching a fixed synthetic child, never removes an uncertain/partial receipt and rejects reuse. Eight concurrent local calls yielded exactly one successful child and seven denials. Tests cover success, nonzero exit, stalled child killed by subprocess timeout, spawn failure, fsync failure, partial/symlink receipts, bad scope and unsafe directory. The only child modes are synthetic success/failure/stall; no transport or provider call is made. The receipt lives in temporary QA storage, not a production ledger. Crash/power-loss persistence, ancestor-directory replacement, process-group descendant cleanup, actual HTTPS worker binding and cross-service rate accounting are not qualified.
