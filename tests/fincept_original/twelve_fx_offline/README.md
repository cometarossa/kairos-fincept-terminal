This QA-only experiment is not imported by Fincept or KAIROS. It makes no requests, changes no credentials, scheduler, relay, runtime policy or production admission. The existing original Twelve Data adapter is unchanged. No provider entitlement or actual payload has been verified.

Run the two explicit test classes from this directory: `python -m unittest -v test_twelve_fx_research_schema_v1.TestSchema test_twelve_fx_transport_qa_v1.TestTransport`. This suite is standalone and is not yet a hosted CI gate.

Candidate scope: one EUR/USD daily series of approximately six months, strict OHLC decimal strings, exact identity metadata, descending provider dates, bounded count and span. The required base/quote metadata and precision constraints are provisional and must be checked against an authorized real response. A missing date can pass shape qualification; no completeness or market calendar attestation is made. A caller-supplied completed-before date is not a market close attestation. Do not mix provider calendars or synthesize volume. Australia/Sydney is the documented forex default, not a verified timestamp for a particular response. No UTC instants are produced.

## Offline transport contract

Physical Zima PID3969886: 13/13 transport tests; PID3970587: 27/27 combined explicit test classes. The fixture planner constructs a fixed EUR/USD daily HTTPS request with a public fake key, and configures a zero-retry HTTPAdapter; it never sends a request. The simulated response evaluator rejects redirects, authentication/rate-limit errors, unexpected HTTP status/content type, oversized or malformed bodies, duplicate JSON keys, invalid constants, and reports fixed error codes. Successful shape qualification remains non-admitted. This is not a tested live transport: TLS verification, egress restrictions, real streaming/decompression, total wall-clock deadline, durable single-attempt accounting and secure real-key handling remain to be implemented/qualified before admission. No real credentials or provider requests used.
